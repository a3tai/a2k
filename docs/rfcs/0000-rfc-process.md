# RFC 0000: A2K RFC process

- **Status:** Active process
- **Audience:** Contributors and maintainers

Normative or governance-significant changes begin as numbered Markdown RFCs in this directory.

An RFC contains: summary, motivation, scope/non-goals, detailed design, security/privacy impact, compatibility, alternatives, conformance changes, implementation plan, and unresolved questions.

Lifecycle:

```text
draft → review → accepted | rejected | withdrawn → superseded
```

Maintainers assign a review window and record material feedback and disposition. Acceptance authorizes specification work; it does not prove implementation or interoperability. An accepted RFC that changes normative behavior must ship with corresponding schemas, fixtures, tests, and compatibility notes.
