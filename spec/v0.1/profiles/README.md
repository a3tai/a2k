# A2K v0.1 profiles

Profiles extend the minimal bootstrap without enlarging the core.

| Profile | Purpose |
|---|---|
| [Governance](governance.md) | ownership, lifecycle, proposals, decisions, invalidation, and archival |
| [Bootstrap](bootstrap.md) | reviewable local agent configuration planning |
| [MCP](mcp.md) | agent-facing resources and tools |
| [Identity](identity.md) | OAuth/OIDC and delegated authorization declarations |
| [Knowledge adapters](knowledge-adapters.md) | external repositories, wikis, catalogs, memory, and research systems |
| [A2A](a2a.md) | references to A2A Agent Cards and compatibility |
| [ACP](acp.md) | coding-agent client compatibility and distribution references |
| [Agent Skills](agent-skills.md) | approved procedural capability references |

Profiles pin external versions and map fields rather than copying external normative definitions. A profile MUST document lossy mappings and trust boundaries.
