# Agent Skills profile — Draft

The Agent Skills profile catalogs approved procedural capabilities without redefining the Agent Skills format.

A skill record references the canonical `SKILL.md` package and records stable identity, version or immutable revision, digest, license, owner, compatibility, requested tool classes, data classification, review status, and approval constraints.

Skill content is executable guidance and therefore higher risk than descriptive knowledge. Catalog presence does not authorize installation, loading, tool access, network access, or execution. Consumers MUST apply artifact review, runtime sandboxing, least privilege, and human approval appropriate to the requested capability.
